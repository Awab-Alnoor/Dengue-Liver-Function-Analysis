# Dengue Fever – Liver Function Analysis

## Project Overview
This project analyzes liver function biomarkers among patients with dengue fever compared with healthy controls in Khartoum State, Sudan.

The project presents the study findings through an interactive Power BI dashboard, focusing on biochemical differences between the two groups and the relationship between AST and ALT.

## Study Design
- Study type: Retrospective case-control study
- Total participants: 60
- Dengue cases: 30
- Healthy controls: 30
- Study location: Al-Raqi Hospital, Khartoum State, Sudan

## Objectives
- Compare liver function biomarkers between dengue cases and healthy controls.
- Explore the distribution of selected biochemical markers.
- Examine the relationship between AST and ALT.
- Present the findings in an interactive Power BI dashboard.

## Biomarkers Analyzed
- Aspartate Aminotransferase (AST)
- Alanine Aminotransferase (ALT)
- Alkaline Phosphatase (ALP)
- Albumin
- Total Protein
- Total Bilirubin

## Tools & Technologies
- Microsoft Excel – Data organization and preparation
- SQL Server – Data querying and analysis
- Microsoft Power BI – Data visualization and dashboard development

## Key Findings
Based on the statistical results reported in the study:

- Albumin was lower in dengue cases (3.35 ± 0.71 g/dL) than in healthy controls (4.10 ± 0.28 g/dL).
- AST was higher in dengue cases (66.15 ± 117.93 U/L) than in controls (18.97 ± 6.29 U/L).
- ALP was lower in dengue cases (81.67 ± 59.54 U/L) than in controls (93.47 ± 19.60 U/L).
- Total bilirubin was higher in dengue cases (0.57 ± 0.45 mg/dL) than in controls (0.34 ± 0.21 mg/dL).
- ALT and total protein did not show statistically significant differences between the groups in the reported analysis.
- A strong positive correlation was reported between AST and ALT in dengue cases (Pearson r = 0.973, p < 0.001).
